# 电脑键盘钢琴

一个不需要构建工具的网页钢琴练习工具。打开 `index.html` 就可以使用电脑键盘或鼠标弹奏，也可以选择曲谱进行跟弹和自由练习。

## 功能

- 电脑键盘、鼠标弹奏，包含白键、黑键和高低音区
- 跟弹模式：按正确音符、按住规定时长，完成后自动进入停顿
- 循环练习：在跟弹模式设置起止音符，反复练习指定片段
- 自由练习模式：显示整首曲谱，可以点击音符查看对应琴键
- 每个音符显示按下时长和停顿，长停顿用更大的左右间距表示
- 曲谱窗口支持拖动、八方向调整大小和内容缩放
- 示范速度调节，示范播放时逐音高亮
- 本地原唱绑定：音频保存在浏览器 IndexedDB，不上传服务器
- 曲库由 JavaScript 数据自动生成，并在启动时校验音符是否属于当前键盘

## 运行

最简单的方式是直接双击 `index.html`。

如果浏览器限制了本地文件的音频或 IndexedDB，可以在项目目录启动静态服务器：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

项目没有 npm 依赖，也没有构建步骤。

## 分段循环练习

选谱后，在跟弹模式填写“从第 / 到第”音符序号，勾选“循环练习”。完成末音和停顿后会回到起点；“重新开始”也会回到循环起点。关闭循环后可继续完整跟弹。切换曲目会重置范围，自由练习模式不循环。“听示范”仍播放整首曲目。

## 使用本地原唱

项目不内置受版权保护的录音。获取拥有合法使用权的音频文件后，在对应曲谱窗口中选择“绑定本地原唱”。文件会按曲目保存在当前浏览器中；点击“听示范”时，钢琴示范和本地音频会同时从设定的起点播放。

原唱起点和示范速度可以分别调整。点击“清除绑定”会删除该曲目的浏览器本地音频记录。

## 添加曲谱

曲谱数据集中在 `index.html` 的 `SONGS` 对象中。每个音符使用下面的格式：

```js
["C4", 0.55, 0.10]
```

三个值分别是音符、按下时长和音符后的停顿。适合重复乐句的数字简谱可以使用 `scaleNotes()`，例如：

```js
notes: scaleNotes("1 2 3 5~ | 5 3 2 1~")
```

新增曲目后，选谱下拉框会自动生成，不需要再手动添加 HTML option。

## 开发检查

运行无需额外依赖的回归测试（需要 Node.js 18 或更新版本）：

```powershell
node --test tests/regression.test.cjs
```

当前项目是单文件前端应用。修改后至少运行：

```powershell
$html = Get-Content .\index.html -Raw
$script = [regex]::Match($html, '(?s)<script>(.*?)</script>').Groups[1].Value
$script | node --check
```

提交曲谱时，请同时说明曲谱来源、调性、节奏依据，以及是否为简化旋律。不要把没有授权的 MP3、视频或抓取脚本提交到仓库。
